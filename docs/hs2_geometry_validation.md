## 骨骼中心不是皮肤解剖点

`mesh_landmarks()` 当前输出的是 FK 后的骨骼中心，没有做蒙皮表面的解剖点提取。名称相同不意味着与照片检测器的点相同：

- `CHEEK_*` 使用上颊骨骼中心，照片后端使用 dlib `14/2`，后者是下颌轮廓点，不是已标定的颧骨最高点。
- `FACE_W_*` 使用耳根骨骼中心，照片后端使用 dlib `16/0` 的侧面轮廓点，两者不具备已验证的测量等价性。
- 眼角、唇缘、鼻尖骨骼可能接近可见特征，但需要逐底模、逐参数区域校准，不能从名称直接认定。
- `GLABELLA` 是眉骨高度的合成中线点，不是实际眉间皮肤点。
- 同一照片检测器用于游戏图和真人照片，仍可能有不同的域偏差、遮挡错误和姿态误差；它不会自动抵消系统误差。

本次三张不同人物卡中，左上颊代理点到 `o_head` 三角形表面的最短距离约为内眼角代理间距的 `22%–39%`，下颊代理约 `19%–26%`。这说明把它们直接称为皮肤表面点不可靠。距离使用同一离线世界坐标下的蒙皮网格和骨骼位置，没有换算毫米。

**最短表面距离不是解剖对应误差。** 最近三角形可能来自错误部位；即使距离为零，也不能证明它是正确解剖点。当前距离只针对头部皮肤网格，未加入独立眼球、牙齿和其他子网格。三张卡的形变参数不同，不能用这些数值给三个底模的表达力排名。

建议的表面测量契约：

1. 每个底模建立独立的语义点表，注明解剖定义、对应三角形／重心坐标、验证样例、适用姿态和误差区间。
2. 固定皮肤特征用表面锚点；图片中的下颌／脸颊外轮廓用**视角相关的可见轮廓**，不拿一个静态顶点代表所有视角。
3. 对眼角、眼睑、唇缘分别检查相关子网格、闭合状态和表情依赖。
4. 校准样例覆盖每个底模的中性状态、常见形变和接近允许边界的形变。验证表面锚点是否随蒙皮移动到正确部位。
5. 标注不确定性来源；遮挡或大侧脸时缺失的点跳过，不填成确定的零误差。

尚未实施这套表面对应关系。现有骨骼代理仍可用于查看控制点趋势，不能作为真人表面测量的无偏真值。

## 59、54、205 与对称性是不同契约

原生人物卡有 `59` 个脸部值。模型的原生块只预测前 `54` 个，耳部 `54–58` 从模板／原卡保留。`205` 维是 `54` 个原生值加上经参数掩码和左右约束保留的 ABMX 分量，不是 `205` 个统一单位的几何测量。

`without_right=True` 在写回时按规定的缩放、位移、旋转镜像符号覆盖右侧相应分量。这是一种表示限制：真人的自然左右差异、照片中的姿态投影和表情不对称不可混为一谈。默认预测向量无法独立表达被镜像的左右参数；原生骨架本身也可能存在基准不对称。

训练向量归一化使用统计 min/max；这不会把各分量变成同等物理效应。原生插值系数、骨骼缩放、局部位移和欧拉角应有独立语义。`set_from_vector()` 的 min/max 转换本身不截断，而比例编辑器会把归一化向量限制到 `[0,1]`。因此其搜索范围不应直接解释为游戏所有控制的合法范围。

任何比较都必须记录底模、59 个原生值、完整 ABMX 状态、保留耳部值和镜像策略，防止模板或被排除的分量悄悄改变结果。

## 用整体曲面和轮廓阻止“比例好了，脸却变形”

少量比值约束有很大的解空间。比如用眼间距作分母，调整眼间距会同时改变许多比值；符合目标比值的脸仍可能过长、额头膨胀或侧面塌陷。STRUCTURAL 子集还排除了弱下颌／颊轮廓指标，这降低测量噪声的同时，也失去了重要的脸型约束。正脸比值几乎不约束深度。

候选拟合的观测向量应同时包含：

- 经标定的五官表面点、局部曲线和区域尺寸。
- 正面与斜面的完整脸部轮廓，以及额头、颧骨、下颌和颏部的区域误差。
- 侧面额头、鼻梁、鼻尖、嘴唇和下巴的曲线与突出程度。
- 对有可信 3D 目标的案例，配准后的表面距离与区域法线误差。
- 单独报告身份相似度和外观差异；beauty score 与参数典型性不充当人物身份目标。

参考照片并不自动提供毫米真值。单张照片的焦距、距离、透视和头部姿态可与脸型混淆；需要共享三维形状、多张照片各自的相机参数，以及相机和重建模型的不确定性。无可信尺度时报告无量纲比例或固定尺度下的误差，并注明尺度定义。

诊断截图采用固定的相机距离、投影、画面尺度、灯光和中性表情，展示正面、左右斜面和左右侧面。候选之间不重新自动填满画面，避免把整体长宽改变隐藏在取景缩放中。照片匹配用的透视相机与这种固定诊断相机分别记录；自动估计相机时设置先验，并用未参与拟合的照片／视角验证。

### 形变质量必须独立于匹配误差

初始可行人物作为基准，分别测量：

- 边长与局部三角形面积的相对变化，区域分位数和最大值。
- 局部应变、拉普拉斯曲面变化，以及额头／颊／下颌区域的连续性。
- 自交、接近坍塌的三角形、异常骨骼尺度和局部蒙皮失稳。
- 眼睑贴合、眼球穿出、唇缘裂缝和牙齿／皮肤穿插。
- 保留的非目标区域是否被同时拉坏。

只看骨骼中心、正值尺度或非退化三角形仍不充分。头部网格不是必然闭合的实体，未经封口和拓扑验证的带符号体积不能当作严格体积指标。多个角度的曲线、横截面和包围范围可先作诊断，真正的体积验收需明确封口与区域定义。

正则项应基于曲面／骨骼的实际变化与误差尺度，而非只惩罚原始参数欧氏距离。阈值需由稳定截图的噪声、表面标定误差和已验收形变案例确定，不能事先编一个通用百分比。质量不合格的候选即使关键点损失下降，也不进入“更像”的结果集。

## 底模表达力比较的可执行顺序

相同目标、表面测量、相机先验、质量约束和验证视角下比较下列模型族。记录每次的起点、计算预算和最优可行候选，避免把更长的优化时间误判成更好的底模。

| 模型族 | 需要回答的问题 |
| --- | --- |
| A：原生 `[0,1]` | 当前原生范围可达到哪些区域？ |
| B：按安装环境验证过的范围外原生插值 | 允许外推是否消除了 A 的主要残差？ |
| C1：原生范围 + ABMX | 独立骨骼控制能否补足形状而保持曲面质量？ |
| C2：经验证外推 + ABMX | 两种扩展组合的收益和质量代价是什么？ |
| D：替换现有底模，重复相同拟合 | 哪个底模达到目标时所需形变最小、验证误差最低？ |
| E：外部三维重建后自动适配底模 | A–D 剩下哪些稳定区域误差值得改变底模？ |

当前离线形变存在端点截断，不能直接拿它评价 B 或 C2；必须先与当前安装环境在原生范围内外的游戏实际网格／多视角轮廓对照。换现有底模也需要可靠的 Sideloader 资产解析和逐底模测量对应，当前三份原生缓存不覆盖全部已安装底模。

各模型族使用多个合理起点，并在独立视角／照片上验收。参数撞边界只说明该次局部拟合受边界影响；一次优化失败只说明该方法没有找到更好结果，两者都不能单独证明底模表达力不足。

### Jacobian 能提供局部诊断，不能证明全局不可达

在候选参数 `p` 附近计算 `J = dY/dp`，`Y` 是按观测误差白化后的表面／轮廓测量。参数列也按实际允许步长或曲面变化标度处理，避免度、距离、插值系数混用产生假的条件数。

将目标残差投影到 `J` 的可信列空间，可区分当前小范围内可调整的残差和暂时没有可见调整方向的残差。同时查看有效秩、小奇异值、活动边界、参数耦合与相机／表情列，判断优化条件是否恶劣。

不过骨骼变形非线性、范围外行为未验证、观测有误差；离开当前位置后可能出现新的方向。因此局部投影残差不是全局表达力证明。应同时用多起点、各模型族比较、留出视角和质量约束形成证据。独立眼网格上的参数在 `o_head` 上导数为零，也不能认定该参数无效。

## 下一阶段产物与验收

1. 参数与安装环境标定：逐底模、逐控制记录实际行为及范围外策略。
2. 表面对应表：给出眼角／唇缘／鼻部等已验证锚点；轮廓使用可见性定义。
3. 固定多视角数据包：原图、拼图、姿态／相机／灯光、人物快照和资产版本。
4. 合成真值回收：使用已知人物参数生成目标，验证能恢复几何而非仅恢复少量比值；处理多组参数产生等价曲面的情况。
5. 真实照片留出评估：按 A–D 分层报告区域残差和质量通过率，说明仍然无法消除的不确定性。
6. 如 A–D 的最佳可行结果仍有稳定偏差，再验证自动重建与底模适配；保留游戏表情、眼口连接和其他使用场景的回归检查。

现有 `scripts/hs2_gt_vs_ours.py` 可复用多视角对照展示，`src/face_metrics/edit.py` 可复用局部求导的框架，但二者均需遵守上述测量和安装环境契约。这里描述的完整评价管线尚未实现，不能据此宣称程儿人物或新的底模已经验收。
