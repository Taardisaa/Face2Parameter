# Optional ALL30 native radial target semantics

`tools/native_radial_target` implements explicit `native_radial_target_v1`:

`target_position = native_local_position * logical_Length + logical_Position`.

Installed physical Length is exactly one; physical Position is target minus predicted native position. Logical Scale and Euler Rotation are preserved. This differs intentionally from installed ABMX's historical-radius first Apply. No semantic fallback, learned coefficient, application-count fit, private write, game writer, or card edit exists in this package.

## Interfaces

- `NativeRadialTargetRig(rig, semantic_mode=MODE, source_bindings=native_source_bindings(rig), device=..., dtype=...)`: differentiable ALL30 positions/scales/rotations, inherited parent-first FK and cached submesh skinning. Inputs are explicit full native59 and B×30×10 logical values. Missing bones, short vectors, default ABMX/card inference and nonpositive scale/Length reject.
- `compile_native_target(history, declared, contract_path)`: requires stopped complete ALL30 clean identity trace plus its exact paired geometry. `history` contains `trace`, `trace_sha256`, and `geometry:{path,sha256,...}`. `declared` has exactly `semantic_mode, head_id, native59, source_history_native59, sampling_profile, logical_patches, source_files`. Logical patches are a dictionary with all 30 source names; `source_files` binds the actual protocol containing those values.
- `prepare_execution_guard(compiled, contract_path, artifact_path=..., artifact_sha256=...)`: reopens sources and regenerates the entire artifact before starting the active observer. Returns a nonserializable process context. `context.verify_snapshot(fresh_geometry, current_trace_metadata)` performs cheap numerical, typed metadata and source-hash checks before applying physical patches.
- `.venv/Scripts/python.exe -m tools.native_radial_target.validate_runtime --manifest <live_cases.json> --contract <installed_contract_v2.json> --out-dir <NEW path>`: independent actual-call replay, exact ALL30 cursor selection, source-only desired locals and full visible cached head/submesh comparison, plus early/late/far60 temporal checks. Default eye-gaze policy refuses unmodeled gaze. Explicit `--source-gaze-policy frozen_source_locals` uses only earlier source `cf_J_look_L/R` locals as declared nuisance and requires them unchanged in every candidate snapshot. It never uses candidate gaze, expression or after to generate targets.
- `.venv/Scripts/python.exe -m tools.native_radial_target.audit_anchored --manifest ... --contract ... --strict-report <preserved strict-false report> --out-dir <NEW path>`: optional `anchored_transform_only_v1` installed branch proof. Requires every channel active, physical Length exactly1, no normalization branch, exact unchanged12 private fields across each observed gap, fixed source/native/actor/bone/modifier identities and no extras/exclusions. It proves incoming-TRS independence of Apply and tests source-only targets against actual after and snapshots. It cannot turn a later overwritten snapshot into a pass; strict report remains unchanged.

## Source and lifecycle contract

Native predictor, installed DLL/decompiled branch sources, sampling profile, head cache, mask/order tables, protocol, source trace/geometry, actor and bridge MVID are bound. Guard requires same actor, exact full59/head, all public modifiers identity, complete typed serial cursor, no additional modifiers/exclusions/H-scene or coordinate-specific branch, no observed external writer boundary, unique actual bone IDs and private cache fields, predicted native local/baseline agreement. Changing native/base/history/profile/assets/DLL invalidates the plan. Numerical rows cannot pass merely by coherently changing a JSON digest: preparation regenerates from immutable originals.

Approximately-zero `_positionBaseline` uses installed `HasLenBaseline` semantics. Sticky length force/restore flags are supported only where this source-specific branch cannot normalize; changed Scale/Rotation/Position and forceApply flags still reject. Nonzero-history pending length flags reject. No claim that arbitrary flags or existing modifiers are safe.

Physical execution needs caller-controlled lifecycle: establish actual native/base without stale modifier reset writes; observe clean identity; stop source observer; compile and prepare; start candidate observer; acquire fresh identity snapshot and guard; apply physical patches; capture bounded actual windows; restore public state. Public snapshot restoration alone does not prove local skeleton restoration. The source-only gate must pass again after any reset/remove/head migration.

## Dimensionality and roundtrip

All 30 source bones and raw 300 logical bone channels are supported explicitly, alongside native59. The legacy ML vector is 205 after native54 and channel/right-side masks. Physical offsets can occupy logical masked channels. Therefore converting physical modifiers back to that vector is not lossless; retain the logical/physical sidecar, semantic mode and source/history bindings. This package does not migrate existing training, inference, optimizer or card consumers.
